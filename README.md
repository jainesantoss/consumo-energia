# Calculadora de geladeira

## 🎯 Objetivo
Calcular o consumo mensal de energia elétrica utilizado em geladeira, com base na potência e no tempo médio de uso diário.

## 📚 Linguagem
* **Python**

## 📱 Fórmula Utilizada
`consumo_mensal = (potencia * horasDia * 30) / 1000`

## 💻 Como Executar
1. Baixe o Python em seu pc.
2. Baixe ou abra o arquivo `app.py`.
3. Execute o programa no seu terminal ou ambiente de desenvolvimento com o comando:
   ```bash
   python app.py
